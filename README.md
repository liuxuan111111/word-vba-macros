# Word VBA 宏合集 · word-vba-macros

> 一套覆盖论文排版高频场景的 Word VBA 宏与模板。

## 问题

Word 论文排版中，参考文献超链接、图片样式统一、批量插图注/表注、编号转文本、按章节号提取角标等操作重复且机械，手动逐条处理工作量大、易出错、格式难以统一。

## 解决方案

编写 12 个 VBA 宏（`.bas`）并搭配 Word 模板（`.dotm`/`.dotx`/`.thmx`），把重复操作封装为一键宏，覆盖参考文献、图片、图注表注、编号、单栏排版等场景。

## 结果

论文排版重复劳动交给宏自动完成，排版效率与格式一致性显著提升，宏文件可复用。

## 文件清单

- 参考文献超链接.bas / 导出引用位置.bas / 导出首次引用位置.bas / 按顺序提取角标页面章节号.bas
- 图片样式.bas / 批量图表.bas / 批量插图注.bas / 选中图片图注表注表格嵌入图片.bas
- 编号转文本.bas / 逐个处理图片图注表注表格设单栏.bas
- 我的模板.dotm / 参考样式1.dotx / 主题1.thmx

## 使用方式

Word → 开发工具 → Visual Basic → 导入 `.bas` 文件后运行对应宏。
